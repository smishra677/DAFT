# DAFT Simulation and Accuracy Scripts
(originally written by Sarthak and refactored by AI) 

This folder contains the scripts used to generate simulated datasets, add gene-tree estimation error, run DAFT, and summarize accuracy.

These scripts support the simulation experiments from the paper **"New approaches to detecting and characterizing introgression in large species trees"** by Mishra et al.

## Requirements

- Python 3
- DAFT and its Python dependencies
- msprime
- pandas
- numpy
- ete3
- matplotlib
- DendroPy, for exporting and rooting IQ-TREE results
- IQ-TREE with AliSim support, for sequence simulation and gene-tree reconstruction

Install DendroPy with:

```bash
python -m pip install dendropy
```

Run commands from the repository root:

```text
DAFT-main/
```

The commands below assume that the scripts have been moved into this directory. If they remain in `scripts/`, prefix each script name with `scripts/`. Always pass the explicit input, output, and executable paths shown for `alisim_C.py`, because its default paths depend on the script location.

## Scripts

### Generate Simulated Datasets

`simulate.py` generates the simulated species trees, demography files, and gene-tree lists used by DAFT.

```bash
python simulate.py
```

Expected output:

```text
DATA_SET/sp_<simulation_id>
DATA_SET/demography_<simulation_id>
DATA_SET/list_<simulation_id>.csv
```

The `list_<simulation_id>.csv` files contain the gene-tree inputs used by DAFT.

### Add NNI Noise

`add_noise.py` adds NNI error to an existing simulated gene-tree file.

The input must be a CSV file with a column named `gt`.

Example:

```bash
python add_noise.py \
  --file DATA_SET \
  --og list_A.csv \
  --error 2 \
  --out list_A_error_2
```

Arguments:

```text
--file    Folder containing the gene-tree CSV
--og      Original gene-tree CSV file name
--error   Mean NNI error used for the Poisson draw
--out     Output prefix
```

Expected output:

```text
DATA_SET/<out>.txt
DATA_SET/<out>.csv
DATA_SET/<out>_log.txt
```

The output CSV contains a `gt` column holding the noisy gene trees.

### Simulate Alignments and Infer Gene Trees

`alisim_C.py` simulates sequence alignments from the original gene trees using AliSim, then reconstructs each gene tree using IQ-TREE. This provides an alternative to adding NNI noise directly.

The input must be a CSV file with a `gt` column containing semicolon-terminated Newick trees. Newick strings containing commas must be quoted within the CSV.

Example:

```bash
python alisim_C.py \
  --input DATA_SET/list_C.csv \
  --output DATA_SET/C_alisim_experiment \
  --iqtree ./iqtree3 \
  --model JC \
  --length 300 \
  --indel 0.004 \
  --branch-length 0.1 \
  --threads 1 \
  --seed 12345
```

Arguments:

```text
--input          CSV containing the original gene trees
--output         New directory for simulation and inference outputs
--iqtree         Path to the IQ-TREE executable
--model          Model used for simulation and inference
--length         Ancestral sequence length before indels
--indel          Insertion and deletion rates, each relative to substitutions
--branch-length  Length assigned to branches without an existing length
--threads        Number of threads for each tree reconstruction
--seed           Starting random seed; incremented for each gene tree
```

This example uses the JC model, 500 ancestral bases, and insertion and deletion rates of 0.004 each. Missing branch lengths are assigned 0.1 substitutions per site; existing branch lengths are retained. Assigned branch lengths are assumptions, not estimates from the input topology. Indels can change the final alignment length.

All input trees are processed. IQ-TREE uses the true alignment generated by AliSim without realignment. The output directory must not already exist.

Expected output:

```text
DATA_SET/C_alisim_experiment/
    input_trees/
    alignments/
    trees/
    logs/
    reconstructed_trees.nwk
    manifest.csv
    settings.json
```

Output contents:

- `input_trees/`: input trees with missing branch lengths filled in.
- `alignments/`: simulated PHYLIP alignments.
- `trees/`: IQ-TREE reconstruction outputs, including `.treefile` files.
- `logs/`: simulation and reconstruction logs.
- `reconstructed_trees.nwk`: reconstructed trees, one per line.
- `manifest.csv`: mappings between input trees, alignments, reconstructed trees, and seeds.
- `settings.json`: run parameters and input tree count.

The explicit values above define this example experiment; they should not be inferred from the script name or its current defaults.

### Export Inferred Gene Trees

`extract_binary_iqtree.py` collects IQ-TREE `.treefile` outputs, attempts to root them using the original gene trees, and writes a CSV for downstream DAFT analysis.

Example:

```bash
python extract_binary_iqtree.py \
  DATA_SET/C_alisim_experiment/trees \
  --reference-csv DATA_SET/list_C.csv \
  --output DATA_SET/list_C_inferred.csv
```

Arguments:

```text
folder           Folder containing IQ-TREE .treefile outputs
--reference-csv  Original gene-tree CSV with a gt column
--output         Output CSV path
--recursive      Include tree files in subfolders
--overwrite      Replace an existing output CSV
```

Files are sorted naturally, so `gene_2.treefile` precedes `gene_10.treefile`, and matched to reference rows by position.

Use the original simulation CSV and ensure that:

- The reference rows follow the same order as the reconstructed gene trees.
- The number of reference rows matches the number of tree files.
- Each reference has exactly two root children.
- Each inferred tree contains exactly the same taxa as its reference.



Each inferred tree is paired with the reference tree at the same row position after naturally sorting the IQ-TREE output files. If the reference root split exists in the inferred tree, the script roots the inferred tree halfway along the matching edge. Otherwise, it retains the inferred tree without reference-based rerooting and resolves polytomies into binary branching.

Ensure that the reference CSV and tree files have matching counts and corresponding order..

Expected output:

```text
DATA_SET/list_C_inferred.csv
```

The output contains a single `gt` column holding the inferred gene trees.

### Run DAFT in Batches

`big_batch_it.py` runs DAFT on the simulated datasets.

```bash
python big_batch_it.py
```

The script assumes that the simulation step has already created:

```text
DATA_SET/list_<simulation_id>.csv
DATA_SET/demography_<simulation_id>
```

The dictionary `sim_dict` maps each simulation ID to the DAFT command template used for that simulation.

The script chunks each gene-tree list, runs DAFT on each chunk, moves the djiNNI cache for each chunk into `DAFT_extras`, and saves the final results for each simulation.

Typical output:

```text
RESULTS/DAFT_results_<simulation_id>
```

For experiments using NNI noise or reconstructed gene trees, configure the batch script to read the corresponding gene-tree CSV while retaining the matching demography file. Creating an alternative CSV does not automatically select it for analysis.

### Extract Inferred Directions

Run the direction extraction script before summarizing djiNNI direction accuracy.

```bash
python accuracy_extract_direction.py
```

`accuracy_extract_direction.py` reads DAFT direction output files and creates:

```text
Summary_direction.csv
```

### Summarize djiNNI Direction Accuracy

`accuracy_djiNNI.py` compares DAFT direction results against the known simulated donor and receiver pairs.

```bash
python accuracy_djiNNI.py
```

In this script, expected introgression links are written as:

```python
expected = [(donor, receiver)]
```

Keep this ordering consistent because the DAFT direction table stores receivers and donors in separate columns.

### Summarize True-Positive Accuracy

`accuracy_tp.py` summarizes true-positive recovery across the simulated datasets.

```bash
python accuracy_tp.py
```

The script compares the known expected introgression links for each simulation against the DAFT output summaries.

Typical output:

```text
Results_rate_uncle_M_TT.csv
Results_rate_sibling_M_TT.csv
```

These files report the total number of simulations checked, false negatives, true positives, the false-negative rate, and the true-positive rate for the uncle-style and sibling-style tests.

### Summarize False-Positive Accuracy

`accuracy_fp.py` summarizes false-positive calls across simulations where specific lineage-pair tests should not be inferred as introgression.

```bash
python accuracy_fp.py
```

Typical output:

```text
Results_rate_uncle.csv
Results_rate_sibling.csv
```

These files report the total number of tests checked, false positives, true positives, the false-positive rate, and the true-positive rate for the uncle-style and sibling-style tests.

### Other Helper Scripts

`extract_gante.py` extracts GANTE results for comparison.

`compare_demography_files.py` compares demography files generated by different simulation scripts.

## Sequence of Actions

### 1. Generate Simulated Data

```bash
python simulate.py
```

### 2. Select the Gene-Tree Input

Use the original simulated gene trees directly, or choose one of the following error experiments.

**Option A: Add NNI noise**

```bash
python add_noise.py \
  --file DATA_SET \
  --og list_A.csv \
  --error 2 \
  --out list_A_error_2
```

Use the resulting file:

```text
DATA_SET/list_A_error_2.csv
```

**Option B: Simulate alignments and reconstruct gene trees**

```bash
python alisim_C.py \
  --input DATA_SET/list_C.csv \
  --output DATA_SET/C_alisim_experiment \
  --iqtree ./iqtree3 \
  --model JC \
  --length 500 \
  --indel 0.004 \
  --branch-length 0.1 \
  --threads 1 \
  --seed 12345
```

Export the reconstructed trees:

```bash
python extract_binary_iqtree.py \
  DATA_SET/C_alisim_experiment/trees \
  --reference-csv DATA_SET/list_C.csv \
  --output DATA_SET/list_C_inferred.csv
```

Use the resulting file:

```text
DATA_SET/list_C_inferred.csv
```

Review the rooting limitation described above before using this output.

### 3. Run DAFT

Configure `big_batch_it.py` to use the selected gene-tree inputs and corresponding demography files, then run:

```bash
python big_batch_it.py
```

### 4. Extract Inferred Directions

```bash
python accuracy_extract_direction.py
```

### 5. Summarize Direction Accuracy

```bash
python accuracy_djiNNI.py
```

### 6. Summarize True-Positive and False-Positive Accuracy

```bash
python accuracy_tp.py
python accuracy_fp.py
```

## Notes

Simulation IDs such as `A`, `B`, `C`, `M`, and `MM` connect the simulated data files, DAFT command groups, demography files, and accuracy checks.

The main file naming convention is:

```text
DATA_SET/list_<simulation_id>.csv
DATA_SET/demography_<simulation_id>
RESULTS/DAFT_results_<simulation_id>
```

Alternative gene-tree inputs should retain a clear connection to their original simulation ID. Examples include:

```text
DATA_SET/list_A_error_2.csv
DATA_SET/list_C_inferred.csv
```

Keep results from different experimental conditions in separate locations to avoid overwriting earlier analyses. Update the relevant script paths and accuracy inputs when switching conditions.

## Reproducibility

The workflow is:

```text
simulate.py
    |
    +-- Original simulated gene trees
    |
    +-- add_noise.py
    |
    +-- alisim_C.py -> extract_binary_iqtree.py
    |
    v
big_batch_it.py
    |
    v
accuracy_extract_direction.py
    |
    v
accuracy_djiNNI.py
    |
    v
accuracy_tp.py / accuracy_fp.py
```

The three branches represent alternative gene-tree inputs for DAFT.

For sequence-based experiments, retain `settings.json`, `manifest.csv`, and the simulation and reconstruction logs. Record the IQ-TREE version and Python dependency versions alongside the results.

The simulation scripts generate the input data, the optional error workflows produce alternative gene trees, the batch script runs DAFT, and the accuracy scripts summarize recovery of the known simulated relationships.
